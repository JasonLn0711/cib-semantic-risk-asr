# Intended Use Statement

Date: 2026-05-26

Scope: CDS-ASR manuscript and aggregate artifact package

## Intended Use

CDS-ASR is intended for high-stakes ASR safety audit and conservative triage
support. Supported uses are:

- ASR safety evaluation;
- risk-aware routing analysis;
- manual review prioritization;
- machine abstention;
- conservative escalation for human confirmation;
- aggregate evidence-chain auditing.

## Out-Of-Scope Uses

CDS-ASR is not intended for:

- automatic guilt or fraud determination;
- automatic account freezing;
- automatic service denial;
- punitive action;
- direct law-enforcement reporting without human review;
- production deployment without separate governance, threshold freeze, privacy
  review, and prospective validation.

## Meaning Of Conservative Machine Action

Conservative machine action means preserving uncertainty and routing the case
toward safer review behavior: abstain, escalate for manual review, keep a
decision interval visible, or require human confirmation. It does not mean
automated adverse action.

## Evidence Scope

The current evidence supports a scoped selected-300 high-stakes audit claim.
It does not estimate population prevalence of ASR-induced harm across all
calls and does not claim live deployment effectiveness.

# Hostile-Reviewer Hardening Checklist

Date: 2026-05-26

Scope: CDS-ASR manuscript submission-prep review hardening

Decision: selected-300 人工審查不用重開。現在的工作是把統計、selection provenance、threshold policy、ethics/governance、artifact reproducibility 寫到 reviewer-proof。

## Core Verdict

稿件 evidence architecture 可以 defend：258-row split 是 model-comparison evidence，selected-300 proxy outputs 是 selection/provenance evidence，30 reviewed rows / 90 reviewed model assessments 是 paper-grade predictor/recovery evidence，release boundary 維持 aggregate-only。

目前真正的投稿風險不是資料 gate，而是 reviewer 會拆四件事：

1. 90 model assessments 是否被錯當 90 independent samples。
2. selected-300 是否造成 metric-family enrichment 或 circularity。
3. best threshold 是否其實是 post-hoc threshold fitting。
4. recovery / intended-use language 是否被寫成 live deployment 或 adverse automation。

## Submission-Prep Analysis Backlog

Do these only from aggregate-safe artifacts or controlled local recomputation:

1. Row-clustered bootstrap CI or leave-one-row-out sensitivity for Table 3 and Table 4.
2. Threshold-budget frontier table: false negatives and severe misses at fixed budgets 10%, 20%, 30%, 40%.
3. Sensitivity excluding rows selected directly by CEIS/SRES-family signals.
4. Aggregate-only variant coverage audit: variants per assessment, source mix, atom mix, rejected variants, no-risk controls.
5. CEIS ablations: no plausibility, uniform atom weights, binary flip only, max versus top-k mean, by-atom class.
6. Artifact manifest refinement with tokenizer/normalization policy, decoding parameters, random seeds, and hardware fields where available. First SHA256/source-commit/environment manifest is generated.
7. Optional blinded second-reviewer spot-check over 5-10 rows, hiding model id and metric scores.

## Manuscript Language Rules

Use:

- "90 reviewed model assessments clustered within 30 reviewed audio rows."
- "selected-300 is an enriched high-stakes audit surface."
- "diagnostic threshold selected on the scoped audit set."
- "aggregate policy replay."
- "CEIS is a conservative decision-stability signal; SRES remains a strong semantic-risk baseline."
- "The policy eliminates severe missed outcomes in replay while residual unsafe downrouting remains."
- "Privacy-preserving aggregate reproducibility rather than public row-level reproducibility."

Avoid:

- "90 independent samples."
- "population prevalence."
- "CEIS universally outperforms SRES."
- "live intervention reduced harm."
- "deployment-ready threshold."
- "all safety risk is eliminated."
- "automatic fraud determination."

## Final Gate Before Submission

The manuscript can move to submission-prep when:

- N-ladder and selection provenance are visible before Results.
- Table 3 uses diagnostic-threshold language and clustered uncertainty caveat.
- Table 4 uses model-assessment units and replay language.
- CEIS/SRES nuance is repeated in Results and Discussion.
- Ethics, Privacy, Intended Use is present with NIH/NIST/EU citations.
- Claim Registry maps each claim to scope, artifact, statistic, and limitation.
- Figure package includes N-ladder and budget-risk frontier.
- Aggregate-only artifact policy remains intact.
- No transcript-bearing artifacts enter repo, README, Slack, ChatGPT, or reviewer-visible release package.
